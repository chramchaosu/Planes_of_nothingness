# Planes of Nothingness

A webcomic reader web app: one small HTML file (`index.html`) plus a `pages/`
folder with the comic pictures.

**Live:** https://chramchaosu.github.io/Planes_of_nothingness/ (GitHub Pages,
deploys from `main`). Open it on a phone and use "Add to Home Screen" to install
it as an app. A service worker (`sw.js`) keeps an offline copy of the app and
fetches new versions automatically; the reader saves every page picture in the
background, so the whole comic works offline.

## Reading

- **Scroll** mode shows an episode as one long strip.
- **Pages** mode shows one page at a time. Swipe, tap the left/right edge, or use
  the arrow keys. Tap the middle to hide the bars.
- Episodes always open on their first page. Each device remembers the preferred
  mode and which episodes were read to the end.

## Project layout

| Path | What it is |
| --- | --- |
| `comic/comic.json` | The list of seasons, episodes and pages, in reading order. Each page's `text` is its caption, or a short description for pages without words (used for screen readers). |
| `comic/season-XX/episode-XX/` | The page images (originals). |
| `src/reader.html` | The reader app (HTML, CSS and plain JavaScript, no libraries). Contains a `__COMIC_DATA__` placeholder. |
| `build.ps1` | Writes phone-sized copies of the pages into `pages/`, fills the placeholder with the comic data, writes `index.html`, and crops the app icons. Pages longer than 1600 px on a side are scaled down. |
| `pages/` | Built page pictures. Names end in a content fingerprint (`s01e03-04-1a2b3c4d.jpg`), so a changed picture gets a new name and can be cached forever. Do not edit; rebuild. |
| `index.html` | The built, ready-to-use app. Do not edit it by hand; rebuild it instead. |
| `tools/split-page.ps1` | Cuts a full comic page into its separate panels. |
| `icon-*.png` | Home-screen icons, generated by the build. |
| `manifest.webmanifest` | App name, colors and icons for "Add to Home Screen". |
| `sw.js` | Service worker: network-first for the app (with a 4 s fallback to the saved copy), saved-copy-first for `pages/`. Bump `CACHE_NAME` when its file list changes. |
| `.nojekyll` | Tells GitHub Pages to serve the files as they are. |

## Building

On Windows, in PowerShell, from this folder:

```powershell
.\build.ps1
```

## Adding an episode

If the episode is drawn as one full page with several panels, cut it into
separate pictures first:

```powershell
.\tools\split-page.ps1 -Page 'C:\path\to\page.jpg' -OutDir comic\season-01\episode-06
```

1. Put the page images in a new folder, e.g. `comic/season-01/episode-02/01.jpg`, `02.jpg`, ...
2. Add the episode to `comic/comic.json` with its `folder` and a `pages` list.
   An optional `"title"` is shown instead of "Episode 2".
3. Run `.\build.ps1` and commit the result.

A new season works the same way: add a season entry with its own `folder`.
